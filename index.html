Panel de Control · Cargar y Sincronizar

Importa el PDF mensual de JetSched o sincroniza con Firebase Realtime Database

Detecta libres/vacaciones (verde), salidas/llegadas MAD (naranja), reservas (morado) y estancias fuera con su ciudad (rojo).

En Firebase Console → Realtime Database → Reglas:

{
  "rules": {
    "turnosFamilia": {
      ".read": true,
      ".write": true
    }
  }
}

Así tu mujer puede leer en tiempo real y tú puedes modificar/sincronizar sin bloqueo de contraseña.
